# 🀄 麻将算账助手 · Mahjong Tally Helper

> 打完麻将，输入每人终局分和台费垫付，一键算清谁该给谁转多少钱，给出一组最少笔数的转账方案。
>
> 🔗 **在线使用**：<https://mohuamoy.github.io/mahjong-tally-helper/>
> 📱 **形态**：纯静态单文件网页，无需下载、无需注册，手机浏览器直接打开。

## ✨ 核心特性

- **一屏算清**：填完即出“应收/应付大字 + 转账清单”，移动端专门做了适配，不同手机一屏看完。
- **台费合并，不单列账**：输入终局分 + 台费垫付/免除，自动计算合并净额。朋友照转账即可，无需理解内部拆分。
- **最少笔数且直觉合理**：算法保证转账笔数 ≤ n-1 笔；同笔数下优先“赢家只收不付”，不出现反直觉的转账中转。
- **零和数学保证**：内部用“分(cent)”整数运算，彻底规避浮点数误差，资金守恒是硬前提。
- **一键导出**：结果可一键复制为文字版“战报”，直接发微信群。

## 🖥️ 界面速览

页面自上而下三块（输入与输出严格分离）：
1. **牌局设置**：日期、分值换算、起始分。
2. **对局表现**：2-6 名牌手的姓名、终局分、台费垫付/免除。
3. **终局结果**：战绩榜单（红输绿赢） + 转账方案（谁→谁 多少钱） + 导出战报。

## 🛠️ 技术方案

- **整体架构**：纯 `HTML + CSS + 原生 JS`，单文件，无后端、无构建工具。算法完全在本地计算，可直接部署，零工具链故障。
- **核心算法**：
  - 输入强校验：`Σ终局分 == 人数 × 初始分`，自动保证净额之和为 0。
  - 整数 cent 运算：`K = 分值换算 × 100`，彻底消灭浮点误差。
  - 最少转账笔数：对合并净头寸做暴力精确枚举（n≤6 瞬间完成），笔数恒 ≤ n-1。
  - 台费并入输赢统一优化：方向相反的两笔自然抵销，进一步省笔数。
- **发布**：GitHub Pages 托管，自动 HTTPS。

## 🚀 使用说明

1. 打开[在线链接](https://mohuamoy.github.io/mahjong-tally-helper/)；
2. 填牌局日期、分值换算、起始分，逐人填终局分；有台费则填金额并指定垫付人、勾选免除名单；
3. 点“生成结果” → 看战绩榜单与转账方案 → 点“导出战报”复制文字版发微信群。

> 本地调试：`index.html` 含“载入示例牌局”按钮（发布版已剥离该入口）。
